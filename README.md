# Hunter_Assassian
This is a stelth game.<br>
<b>Objective</b> : The Objective is to help your character to kill all enemies present in a level to win the level.
The enemies are patroling, teleporting, cloning based on the current game state and player's proximity.
As the level increases the difficulties increases.

<h3>How To Play</h3>
Start the game.<br>
choose level.<br>
Use arrow keys or a,w,s,d keys to move and space bar to kill. If you are close to enemy They will shoot you and if you are going away. They will chase you.
